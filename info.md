## 12. Positioning Vocabulary

*Reusable phrasing bank from `vision.md` — for resumes, LinkedIn, and cover letters.*

### Strategic Paradigms
- **AI-Native Architecture:** Designing systems where AI is a core component rather than an add-on.
- **The AI Engineering Lab Paradigm:** A framework for evolving raw requirements into production-ready agents.
- **Digital FTE (Full-Time Equivalent):** Describing AI agents not as tools, but as autonomous employees performing end-to-end work.
- **Convergent Validation:** Using independent data points (benchmarks, market trends, academic results) to justify technical decisions.
- **Self-Disrupting Software:** The concept of software tools evolving to change how software itself is built.

### The Agent Maturity Model
- **General Agent Incubation:** Using multi-purpose reasoning systems for discovery and rapid iteration.
- **Crystallization Phase:** Extracting working patterns from prototypes into formal specifications.
- **Specialist (Custom) Agents:** Purpose-built systems optimized for reliability, speed, and governance.
- **Dynamic Planning:** Enabling agents to decompose goals into subtasks on the fly without pre-defined templates.
- **Context-Aware Reasoning:** Systems that autonomously scan and understand local repository structures and tech stacks.

### Technical Roles & Skills
- **Agentic Orchestration:** Managing the interaction between multiple AI agents.
- **Specification Writing:** Crafting high-precision technical "intents" that determine AI output quality.
- **Guardrail Engineering:** Building hard limits and safety constraints into autonomous systems.
- **Human-in-the-Loop (HITL) Collaboration:** Efficiently directing AI systems while maintaining oversight.
- **Operational Excellence for LLMs:** Engineering for constraints like latency, token costs, and determinism.

### Performance & Metrics Language
- **10x Productivity Paradigm:** Quantifiable jumps in engineering throughput via AI-native workflows.
- **Resolution Rate:** The percentage of tasks handled by an agent without human escalation.
- **Escalation Triggers:** Defined logic that determines when an AI should hand off to a human.
- **Systemic Multipliers:** Using AI tools to effectively "add headcount" without hiring.
